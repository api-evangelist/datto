# Datto

> Datto (part of Kaseya) is a data-protection and IT-management vendor for managed service providers. It offers business continuity and disaster recovery (SIRIS, ALTO, Endpoint Backup), SaaS Protection, Remote Monitoring and Management (Datto RMM), Autotask PSA, networking, and cybersecurity. Datto RMM publishes a versioned REST API (v2, OpenAPI 3.1) over regional CentraStage hosts, secured with OAuth 2.0, rate-limited, and paginated.

## APIs
- [Datto RMM API v2 (docs)](https://rmm.datto.com/help/en/Content/2SETUP/APIv2.htm): Manage sites, devices, alerts, jobs, audits, variables, users, and system status.
- [Datto RMM API reference (Swagger UI)](https://concord-api.centrastage.net/api/swagger-ui/index.html): Interactive OpenAPI 3.1 reference.
